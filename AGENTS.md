# Accord Ledger

Standalone project. Do not import, copy, or depend on RealtimeApp, Diktum, or Word_add_on.

- Read README.md and docs/HACKATHON.md before changing submission claims.
- Document text, extracted proposals, approved terms, and external evidence are different objects.
- Never execute a model-generated action or deploy arbitrary model-generated Solidity.
- Bind approvals and evidence to the exact version/hash of the terms.
- Missing, conflicting, stale, or wrong-version evidence must block automatic release.
- Keep client documents and credentials out of source control and public chain payloads.
- Use synthetic data and local EVM/testnets. No real-value transaction is authorized by repository instructions.
- Store any future LLM prompts in prompts/, with explicit schemas and tests; no hidden prompts in application code.
- Record new work and external dependencies in docs/PROVENANCE.md.
- Run npm run check before declaring the starter verified. Local tests do not prove CRE simulation or deployment.
- Do not mark the hackathon submission ready until all required evidence in docs/HACKATHON.md exists.
